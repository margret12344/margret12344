### 02. AI Research Navigator
**AI-Powered Research Discovery & RAG Assistant**

</div>

A full-stack research assistant that enables users to discover academic papers and AI models across arXiv, OpenAlex, GitHub, and Hugging Face, then interact with retrieved information conversationally.

**Key Features:**
- Multi-source research discovery.
- Semantic search using ChromaDB.
- Grounded RAG-based conversational assistant.
- Local LLM integration using Ollama.
- Source verification and roadmap generation.
- SQLite-backed conversation history.

**Engineering Highlights:**
- FastAPI backend and Streamlit frontend.
- Lazy-loaded RAG architecture.
- Modular integration of existing NLP and retrieval components.
- Collaborative development with 3 contributors.

**Technologies:** Python, FastAPI, Streamlit, ChromaDB, Ollama, RAG, SQLite.
